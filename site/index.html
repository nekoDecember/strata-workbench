04 / FOLLOW THE ROW

選択は、調査のしおり。

「気になったもの」を選択として残すと、グラフから表、Pythonまで同じ集団を追跡できます。

選択は削除ではない

選択モードを使い分ける

上部の「選択」には、グラフとセル範囲に効く3つのモードがあります。下で押して挙動を確認できます。

置換：新しい集団を見る今の選択を入れ替えます。まずはこれで「この点だけ」を確認。
表のチェックはページをまたいだ選択を保持します。選択行のみは表示を絞るだけで、元データを削除しません。

選択・条件・除外の違い

似た操作を、役割で分けて覚えると事故が減ります。

  • 選択：気になる行をマーク。要約の「選択」列やPythonの selected に反映。
  • 条件：列の値で母集団を絞る。グラフ・表・要約・Pythonの対象が変わる。
  • 選択行のみ：選択した行だけを表示する。一時的な確認に便利。
  • 除外：分析対象から外す。解除リンクで戻せる。
↔
行IDが橋渡しをする。グラフの点やPythonの集約表から戻ってこられるのは、内部の予約列 __row_id が元の観測を指し続けるからです。集約後の行は、その行に対応する元のIDをリンクとして持てます。

06 / PYTHON

Pythonは、探索の続きを書く場所。

画面の状態を手でコピーし直す必要はありません。実行時点のリビジョン・表示条件・選択行・コードがジョブとして保存されます。

Ctrl / ⌘ + Enter で実行

まず覚える4つの受け取り口

画面内Pythonでは、表示条件に一致する全行が df に入り、選択行は別の selected に入ります。

ワーカーが別プロセスで実行
df表示条件に一致する全行。描画サンプルではない。
selecteddfのうち、現在選択されている行。
context現在のX / Y / 層別 / データ名など。
# 表示中の条件で、Y列を要約
value = context["y"]
group = context.get("group")

if group:
    summary = df.groupby(group, dropna=False)[value].agg(
        ["count", "mean", "std", "median"]
    )
else:
    summary = df[[value]].describe()

wb.show(summary, name="現在の切り口で要約")
# 各集約行に、対応する元の行IDを渡す
group, value = context["group"], context["y"]
groups = list(df.groupby(group, dropna=False))
summary = pd.DataFrame([
    {group: key, "平均": part[value].mean()}
    for key, part in groups
])
wb.show(summary, name="層別サマリー",
        row_ids=[part["__row_id"].tolist()
                 for _, part in groups])
# 元の行IDを残したまま、派生列を追加
value = context["y"]
out = df.copy()
out["平均との差"] = out[value] - out[value].mean()

# 「表に戻す」で新しい派生データとして開く
wb.publish(out, name="平均からの差を追加")
↗
出力の行リンクは、今のデータID・リビジョンと一致すると使える。wb.show()は表・Plotly図・Matplotlib図・テキストを返せます。wb.select(ids)はPythonの条件で行を選ぶだけで、削除や除外はしません。
07 / SAVE & HAND OFF

最後に、再現できる形で残す。

Strataは元データを直接上書きせず、変更や派生結果をリビジョンとして積み上げます。戻る道を残したまま、次の分析へ渡せます。

保存は自動 / 引き継ぎは任意

読み込み時のチェック

ファイルでもPostgreSQLでも、最初に列の型と欠損を確認しておくと、その後のグラフ選びがスムーズです。

  • ファイル：CSV / TSV / Parquet / XLSX。CSVはUTF-8、CP932、Shift JISと区切りを指定できます。
  • PostgreSQL：登録済み接続から読み取り専用SQLでスナップショットを取り込みます。
  • 型：数値・文字列・日時。列の型変更は新しいリビジョンになります。
ファイル上限 128MiBSQL取込 最大20万行

履歴と引き継ぎ

右上の r番号から過去のリビジョンを確認できます。分析メモも同じ状態に残せます。

元データr1 · 保持
セル編集 / 型変更新しいr
Python publish派生データ
Notebook現在の条件を固定

書き出しはParquet（型を保ちたいとき）かCSV（共有しやすさ重視）。画面下の「Notebookに引き継ぐ」も使えます。

✓
個人用の信頼できるコードを動かす環境として使う。Pythonワーカーはネットワークや秘密ファイルから分離されていますが、悪意あるコードを受け取るための完全なマルチユーザーサンドボックスではありません。
CHEAT SHEET / FAQ

つまずいたときの、短い答え。

必要なところだけ開く
何から触ればいい？

「サンプルで試す」→散布図でYを選ぶ→点を2つ囲む→表の選択行を見る、の順です。ここまでできればStrataの核は掴めています。

点を選んだのに表が絞られない

選択は母集団を変えず、行をマークする操作です。表だけにしたい場合はデータテーブルの「選択行のみ」を押してください。条件で母集団を変える場合は左の「条件」を追加します。

グラフの点が全行ないように見える

散布図と時系列は多いデータを最大5,000点まで描画サンプリングします。全行を計算している要約・ヒストグラム・箱ひげ図と役割が違います。細かく見たい期間や群を先に絞ってください。

Pythonの結果が表に戻せない

実行時のデータID・リビジョンと現在の画面が一致しているか確認してください。集計表から元行へ戻すには、各集約行に対応する row_ids を渡します。
